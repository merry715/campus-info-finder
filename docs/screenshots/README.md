# 스크린샷 캡처 가이드

이 폴더에 제출용 스크린샷을 넣어 주세요.
Claude Code는 브라우저를 직접 열 수 없으므로 아래 안내에 따라 직접 캡처해야 합니다.

---

## 캡처 환경

- 브라우저: Chrome (권장)
- 창 너비: 1280px 기준
- 로컬 서버: `python -m http.server 8080` → `http://localhost:8080`

---

## 캡처할 화면 목록

### 01-main.png — 기본 통합 목록

- URL: `http://localhost:8080` (해시 없음, 기본 상태)
- 조건: 검색어·필터 없음, 1페이지
- 확인 항목: 샘플 배너, 샘플 기준일(2026-11-10), 카드 목록 10건, 출처 배지, 페이지네이션

---

### 02-search.png — 키워드 검색 결과

- URL: `http://localhost:8080/#/?q=%EC%A1%B8%EC%97%85%EC%9A%94%EA%B1%B4`
  (또는 검색창에 "졸업요건" 입력 후 검색)
- 조건: 검색어 "졸업요건"
- 확인 항목: 여러 출처(학과공지, 학사공지)의 결과가 섞여 표시, 조건 칩에 검색어 표시

---

### 03-filter.png — 출처+기간 필터 적용

- URL: `http://localhost:8080/#/?src=haksa&period=3m`
  (또는 기간 "최근 3개월" + 출처 "학사공지" 선택)
- 조건: 출처 = 학사공지, 기간 = 최근 3개월
- 확인 항목: 필터 사이드바 선택 상태, 조건 칩, 결과 건수(5건), haksa-004 포함

---

### 04-detail.png — 게시물 상세 화면

- URL: `http://localhost:8080/#/item/dept-001`
  (또는 "2026학년도 졸업요건" 카드 클릭)
- 확인 항목: 출처 배지, 게시일, 게시 부서, 본문, 첨부(샘플·다운로드 불가), 원문 보기(비활성), "검색 결과로 돌아가기"

---

### 05-empty-recovery.png — 결과 없음 + 복구 화면

- URL: `http://localhost:8080/#/?q=%EC%9E%A5%ED%95%99%EA%B8%88%20%EB%A7%88%EA%B0%90&src=career`
  (또는 검색어 "장학금 마감" + 출처 "취업정보" 선택)
- 조건: 결과 0건
- 확인 항목: "검색 결과가 없습니다" 메시지, 현재 조건 요약, "전체 출처에서 다시 찾기" 버튼, "모든 조건 초기화" 버튼
